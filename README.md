# Foodsharing Warszawa

Statyczny szablon strony opublikowany do oceny na [GitHub Pages](https://przemowakcji.github.io/foodsharing-warszawa/).

Podgląd lokalny: `python3 -m http.server 8766`, następnie `http://localhost:8766`.

Przed uznaniem wersji za docelową należy potwierdzić regulamin i uzupełnić aktualną listę jadłodzielni. Strona celowo nie podaje niezweryfikowanych adresów ani godzin otwarcia.

Logo Foodsharing Polska pochodzi z [obecnej strony organizacji](https://www.foodsharing.pl/wp-content/uploads/2023/07/cropped-cropped-190324_Logo-Foodsharing-Polska-1-768x263.png) i jest zapisane lokalnie w `assets/foodsharing-polska.png`.
